# Guide — saisir les traductions arabes des 5 produits

Durée estimée : 15 à 25 minutes par produit [HYPOTHÈSE]. Rien n'est obligatoire : un champ laissé vide s'affiche
en français dans la boutique en arabe. Le français n'est jamais modifié par ces champs.

## Avant de commencer

1. **D'abord finaliser le français.** Dans la base de développement, plusieurs textes français sont encore des
   textes d'attente : « À confirmer selon la fiche officielle du produit » (types de peau) et « Liste INCI complète :
   à reprendre de l'emballage officiel » (ingrédients). **Ne pas les traduire** : les remplacer d'abord par les vraies
   informations de l'emballage, puis traduire.
2. Compte : Propriétaire, Admin ou Éditeur de contenu (Gestionnaire et Analyste ne peuvent pas modifier).
3. Ton : neutre, pluriel de politesse ou tournure impersonnelle (« يُرجى… », « استعملوا… »), comme le reste du site.
4. Les **noms de marque** restent en latin : Baroness, SOME BY MI, BIOVÈNE / Biovène, Quret, ORJENA.

## Étapes (pour chaque produit)

1. Admin → **Produits** → ouvrir le produit.
2. Descendre jusqu'au bloc **« Version arabe (العربية) »** (sous « Contenu du soin »). Le texte français est affiché
   en gris sous chaque champ, comme repère.
3. Remplir les champs (tableau ci-dessous).
4. Cliquer sur **« Enregistrer »** (en bas de l'écran : « Modifications non enregistrées »).
5. **Catégories** : le nom arabe se saisit dans le même bloc et s'enregistre avec le petit bouton « Enregistrer » de sa
   ligne. Il est commun à tous les produits de la catégorie : une seule saisie suffit.
6. Vérifier sur la boutique : bouton **« العربية »** en haut → ouvrir la fiche du produit.

## Champs à remplir

| Champ (admin) | Où il apparaît | Limite | Conseil |
|---------------|----------------|--------|---------|
| Nom affiché (arabe) | Titre de la fiche, cartes, panier | 255 car. | Garder la marque en latin, ex. « جل Baroness بالألوفيرا » |
| Description courte (arabe) | Sous le nom sur les cartes produits | 160 car. | Une phrase |
| Description (arabe) | Haut de la fiche + rubrique « الوصف » | 5 000 car. | 1 à 2 phrases |
| Description complète (arabe) | Rubrique « الوصف » | 20 000 car. | Facultatif (vide en français aussi pour l'instant) |
| Ingrédients (arabe) | Rubrique « المكونات » | une ligne par ingrédient | Mêmes lignes que le français, dans le même ordre ; noms INCI en latin |
| Bienfaits (arabe) | Rubrique « أبرز المزايا » | une ligne par bienfait | Aucune promesse médicale |
| Conseils d'utilisation (arabe) | Rubrique « طريقة الاستعمال » | une étape par ligne | Même nombre d'étapes que le français |
| Types de peau (arabe) | Ligne « نوع البشرة » | 255 car. | Seulement quand le français est confirmé |
| Pictos (arabe) | Petites tuiles de la fiche | 60 car. par picto | Un champ par picto, dans l'ordre français |
| Catégories (arabe) | Filtres, badges, fil d'Ariane | 100 car. | Une fois par catégorie |

Non traduisibles pour l'instant : options de variantes (« Contenance », « 50 ml »), textes alternatifs des images,
titre et description servis aux moteurs de recherche.

## Contrôle final (par produit)

- [ ] Fiche en arabe : titre, description, rubriques et pictos en arabe, sans coupure de mots.
- [ ] Fiche en français : textes inchangés.
- [ ] Carte produit (page « منتجاتنا ») : nom et description courte en arabe.
- [ ] Ajout au panier en arabe : le nom affiché dans le panier est le nom arabe.
